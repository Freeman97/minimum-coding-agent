# minimum-coding-agent

一个学习为目的建立的最小可用的 ReAct 风格 Coding Agent。

## 架构
* 基于 LangChain 和 LangGraph 搭建。
* 单 Agent 模式。

## 功能
包含以下功能：
* 多轮会话
* 代码生成与编辑
* 可配置的 LLM 接入点：暂时只支持 OpenAI 格式请求，预留支持其他请求格式（如 Anthropic）的扩展点
* 文档搜寻
* 规划与 TODO 列表
* 代码定位
* MCP 集成、命令扩展（`/`开头的命令集）、自定义 Instructions（`AGENT.md`）
