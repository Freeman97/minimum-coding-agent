# Spec Delta

## Purpose

定义可配置模型接入点的外部行为：如何选择与配置模型提供商、如何以流式方式调用 OpenAI 兼容端点、失败如何呈现，以及新增提供商的扩展契约。

## ADDED Requirements

### Requirement: Provider 选择与配置

系统 SHALL 通过配置选择模型提供商，MVP 仅内置 OpenAI 兼容提供商；配置 SHALL 覆盖端点地址、API Key 来源、模型名、温度、最大输出与超时。

#### Scenario: 使用 OpenAI 兼容端点

- **WHEN** 配置声明提供商为 OpenAI 兼容且端点、模型与密钥齐备
- **THEN** 系统创建可用的聊天模型并通过该端点完成调用

#### Scenario: 未知提供商

- **WHEN** 配置声明了未注册的提供商名称
- **THEN** 启动终止并列出当前可用的提供商名称

#### Scenario: 密钥不落配置文件

- **WHEN** API Key 通过环境变量提供
- **THEN** 系统正常读取，且配置文件无需包含明文密钥

### Requirement: 流式对话调用

系统 SHALL 以流式方式调用模型并持续上报增量输出；流结束时 SHALL 给出完整最终消息。

#### Scenario: 增量输出可见

- **WHEN** 模型逐片段返回内容
- **THEN** 消费方在流结束前即可收到增量片段

#### Scenario: 流正常结束

- **WHEN** 流式调用正常完成
- **THEN** 消费方收到完整最终消息，且片段顺序不丢失

#### Scenario: 流被中断

- **WHEN** 流式调用中途中断
- **THEN** 系统发布可报告的错误事件，已接收内容不丢失

### Requirement: Provider 扩展契约

系统 SHALL 支持在不修改 Agent 循环、工具系统与控制台界面的情况下注册新的模型提供商；扩展契约 SHALL 有文档说明与测试样例。

#### Scenario: 注册新提供商

- **WHEN** 按契约注册一个测试用提供商并在配置中选择它
- **THEN** Agent 可通过该提供商完成多轮对话

#### Scenario: 契约不合规

- **WHEN** 新增提供商未实现契约要求的接口或字段
- **THEN** 注册或启动阶段给出明确的错误信息

### Requirement: 模型调用错误处理

系统 SHALL 将认证失败、网络错误、超时与服务端错误转换为用户可读错误，且 SHALL 不使进程崩溃或卡死。

#### Scenario: 认证失败

- **WHEN** 端点返回认证失败
- **THEN** 提示检查 API Key 与端点地址，且错误信息中不出现密钥内容

#### Scenario: 请求超时

- **WHEN** 调用超过配置的超时时间
- **THEN** 终止本次调用、提示超时，并恢复可继续交互的状态

#### Scenario: 服务端错误

- **WHEN** 端点返回 5xx 或不可解析响应
- **THEN** 提示服务端错误摘要并允许用户重试，进程不退出
