# Spec Delta

## Purpose

定义通过 MCP 动态引入外部工具的配置、加载、命名空间、调用与失败隔离行为，使 Agent 能在不改核心代码的情况下扩展能力。

## ADDED Requirements

### Requirement: MCP 服务器配置

系统 SHALL 从配置读取 MCP 服务器列表，每项包含名称、传输方式与启动参数；非法配置 SHALL 在启动时给出明确错误。

#### Scenario: 合法 stdio 服务器

- **WHEN** 配置包含一个字段完整的 stdio 服务器
- **THEN** 系统在启动后尝试连接并加载该服务器的工具

#### Scenario: 配置非法

- **WHEN** 服务器名称为空、重复或缺少必填字段
- **THEN** 启动失败并指出有问题的配置项

#### Scenario: 不支持的传输方式

- **WHEN** 配置声明了 MVP 不支持的传输方式
- **THEN** 提示不支持并列出当前可用方式

### Requirement: 工具加载与命名空间

系统 SHALL 将 MCP 工具转换为内部工具并暴露给模型；工具名称 SHALL 带服务器命名空间，以避免与内置工具或其他服务器工具冲突。

#### Scenario: 加载 MCP 工具

- **WHEN** MCP 服务器成功提供工具
- **THEN** 这些工具以带命名空间的名称出现在模型可用工具列表中

#### Scenario: 名称冲突

- **WHEN** MCP 工具与内置工具或另一服务器工具重名
- **THEN** 两者可通过命名空间区分，且注册不冲突

#### Scenario: 禁用服务器

- **WHEN** 配置禁用了某个 MCP 服务器
- **THEN** 其工具不被加载，其他工具保持可用

### Requirement: 生命周期与失败隔离

MCP 连接 SHALL 在应用生命周期内管理，并在应用退出时关闭；单个服务器不可用 SHALL 仅产生警告，不影响应用启动与其他工具。

#### Scenario: 服务器启动失败

- **WHEN** 某个 MCP 服务器启动或握手失败
- **THEN** 应用继续启动，提示该服务器不可用，其余功能正常

#### Scenario: 应用退出

- **WHEN** 应用退出
- **THEN** 所有 MCP 连接被关闭，不遗留子进程

#### Scenario: 调用超时或报错

- **WHEN** MCP 工具调用超时或返回错误
- **THEN** 返回结构化错误给模型，Agent 循环继续

### Requirement: MCP 工具调用

系统 SHALL 使用 MCP 工具声明的参数结构进行调用，并将调用结果或错误以工具结果形式返回模型。

#### Scenario: 合法调用

- **WHEN** 模型调用 MCP 工具且参数符合声明结构
- **THEN** 系统执行调用并返回结果摘要

#### Scenario: 参数非法

- **WHEN** 模型提交的参数不符合工具声明的结构
- **THEN** 返回结构化参数错误，不发起远程调用

### Requirement: MCP 集成可验证

项目 SHALL 提供一个可离线运行的示例 MCP 服务器或替身，用于验证加载、命名空间、调用与失败隔离行为。

#### Scenario: 离线验证

- **WHEN** 运行 MCP 相关测试
- **THEN** 使用替身服务器验证加载与调用，不依赖外网

#### Scenario: 真实服务器接入

- **WHEN** 用户提供真实 MCP 服务器配置
- **THEN** 可通过配置接入并完成一次工具调用
