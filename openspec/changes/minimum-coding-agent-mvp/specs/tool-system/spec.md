# Spec Delta

## Purpose

定义 Agent 可使用的工具执行能力与安全边界：工具如何注册与暴露、文件与命令操作如何被限制在工作区内、失败如何以结构化结果回传模型。

## ADDED Requirements

### Requirement: 工具注册与暴露

系统 SHALL 提供统一的工具注册机制，将已启用工具集的工具名称、描述与参数结构暴露给模型；同名工具 SHALL 被拒绝注册。

#### Scenario: 工具集加载

- **WHEN** 系统加载一个启用的工具集
- **THEN** 其中每个工具出现在模型可用工具列表中，并携带名称、描述与参数结构

#### Scenario: 工具重名

- **WHEN** 两个工具集暴露了同名工具
- **THEN** 注册失败并指出冲突的工具名称

#### Scenario: 禁用工具集

- **WHEN** 配置禁用了某个工具集
- **THEN** 其工具不再暴露给模型，其他工具保持可用

### Requirement: 工作区路径边界

系统 SHALL 将文件读写、检索与代码定位操作限制在工作区根目录内；越界路径（绝对路径逃逸、`..` 或符号链接逃逸）SHALL 被拒绝并以结构化错误返回模型。

#### Scenario: 访问工作区内文件

- **WHEN** 工具请求读取或写入工作区内的路径
- **THEN** 操作正常执行

#### Scenario: 读取工作区外文件

- **WHEN** 请求读取工作区外文件，包括通过 `..` 或符号链接逃逸
- **THEN** 返回拒绝错误，且不访问目标文件

#### Scenario: 写入工作区外路径

- **WHEN** 请求写入工作区外的路径
- **THEN** 返回拒绝错误，且文件系统保持不变

### Requirement: 文件读取与编辑

系统 SHALL 提供列目录、按行范围读取文件、创建或覆盖文件与唯一文本替换的工具；对二进制文件、超大文件与非法编码 SHALL 给出明确错误或安全截断。

#### Scenario: 按行范围读取

- **WHEN** 请求读取文件的指定行范围
- **THEN** 返回对应行内容并标注文件总行数

#### Scenario: 唯一文本替换

- **WHEN** 替换目标文本在文件中唯一出现
- **THEN** 仅该处被修改，其余内容保持不变

#### Scenario: 替换目标不唯一或不存在

- **WHEN** 替换目标文本出现多次或完全不存在
- **THEN** 返回错误说明且不修改文件

#### Scenario: 二进制或超大文件

- **WHEN** 目标文件为二进制或超过配置的大小上限
- **THEN** 返回拒绝或截断提示，而不是崩溃或输出乱码

### Requirement: Bash 命令执行

系统 SHALL 在工作区目录执行非交互式命令，支持超时终止、输出截断与退出码返回；对危险命令 SHALL 提供执行前确认钩子。

#### Scenario: 输出截断

- **WHEN** 命令输出超过配置上限
- **THEN** 保留头部与尾部并明确标注截断

#### Scenario: 命令超时

- **WHEN** 命令运行超过配置的超时时间
- **THEN** 终止该命令并返回超时错误

#### Scenario: 命令失败

- **WHEN** 命令以非 0 退出码结束
- **THEN** 返回退出码与标准错误输出，供模型决策

#### Scenario: 危险命令确认

- **WHEN** 命令命中危险命令规则且确认钩子拒绝执行
- **THEN** 命令不执行并返回拒绝原因

### Requirement: 工具失败语义

系统 SHALL 将工具的可预期失败作为工具结果返回给模型，而不是以异常终止 Agent 循环。

#### Scenario: 工具返回业务错误

- **WHEN** 工具因参数错误、路径越界或权限不足失败
- **THEN** 模型收到结构化错误文本并继续下一轮决策

#### Scenario: 工具发生未预期异常

- **WHEN** 工具执行中抛出未预期异常
- **THEN** 异常被转换为错误结果并记录日志，Agent 循环不崩溃
