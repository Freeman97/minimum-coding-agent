# Spec Delta

## Purpose

定义工作区内的文本检索与代码定位能力，降低 Agent 盲目读取文件的成本，并为未来多语言代码分析预留扩展架构。

## ADDED Requirements

### Requirement: 工作区文本检索

系统 SHALL 提供文本检索工具，支持关键词与正则查询、路径过滤，并返回工作区相对路径、行号与匹配片段。

#### Scenario: 关键词检索

- **WHEN** 使用关键词检索工作区
- **THEN** 返回按文件与行号排列的匹配片段

#### Scenario: 正则检索

- **WHEN** 使用合法的正则表达式检索
- **THEN** 返回符合模式的匹配；正则非法时返回明确的语法错误提示

#### Scenario: 路径过滤

- **WHEN** 检索指定了文件名或目录过滤条件
- **THEN** 仅返回满足过滤条件文件中的匹配

### Requirement: 检索安全与效率边界

检索 SHALL 跳过版本库元数据、虚拟环境、依赖目录、二进制文件与超大文件，并限制结果数量与单条长度。

#### Scenario: 跳过无关目录

- **WHEN** 工作区包含版本库元数据、虚拟环境或依赖目录
- **THEN** 这些目录中的内容不被检索

#### Scenario: 结果超限

- **WHEN** 匹配数量超过配置上限
- **THEN** 返回部分结果并明确标注已截断

#### Scenario: 命中二进制文件

- **WHEN** 检索命中二进制文件
- **THEN** 跳过该文件，不输出乱码内容

### Requirement: Python 代码定位

系统 SHALL 提供 Python 代码定位能力：文件大纲（类、函数、方法及其行号范围）、按名称查找定义、按标识符查找引用；对存在语法错误的文件 SHALL 降级处理而不使工具整体失败。

#### Scenario: 生成文件大纲

- **WHEN** 请求某个 Python 文件的大纲
- **THEN** 返回其中类、函数、方法的名称、类型与行号范围

#### Scenario: 查找定义

- **WHEN** 按名称查找定义
- **THEN** 返回工作区内匹配的定义位置（相对路径与行号）

#### Scenario: 查找引用

- **WHEN** 按标识符查找引用
- **THEN** 返回该标识符出现的位置，并标注结果为近似（非类型级语义）

#### Scenario: 文件语法错误

- **WHEN** 目标文件存在语法错误
- **THEN** 返回可用的部分信息或明确提示解析失败，不抛出未处理异常

### Requirement: 多语言 AST 扩展架构

代码定位 SHALL 通过语言提取器注册机制实现，MVP 仅注册 Python；新增语言 SHALL 不需要修改 Agent 循环、工具注册与控制台界面。

#### Scenario: 支持语言清单

- **WHEN** 查看当前支持的代码定位语言
- **THEN** 仅声明 Python 为已支持语言

#### Scenario: 注册新语言

- **WHEN** 按契约注册一个新的语言提取器
- **THEN** 该语言文件可被定位，且其他语言行为保持不变

#### Scenario: 未支持语言

- **WHEN** 对未支持语言的文件请求代码定位
- **THEN** 返回"暂不支持"或正则降级结果，不崩溃

### Requirement: 结果输出约束

检索与定位结果 SHALL 使用工作区相对路径、按位置排序，并限制结果总大小，避免占用过多上下文。

#### Scenario: 结果截断

- **WHEN** 检索或定位结果超过总大小上限
- **THEN** 输出按上限截断并明确标注

#### Scenario: 路径格式

- **WHEN** 结果中展示文件位置
- **THEN** 使用相对于工作区的路径格式
